# AI Plugin IDE Implementation Plan

**Goal:** Create, edit, preview and publish AI-assisted plugins inside Savia.

**Architecture:** Dedicated authenticated AI generator; browser compiler with
isolated mock preview; lazy IDE integrated into the existing workspace store.

**Tech stack:** React, Monaco, Sucrase, Vite/esbuild, AI SDK, Zod, tenant store API.

**Spec:** ../specs/2026-10-04-plugin-ide-design.md

## Constraints and review focus

- Keep credentials server-side and bind generation to an authorized tenant.
- Validate structured AI output and all project files before applying/publishing.
- Reject stale preview and stale AI results; preserve user edits after failures.
- Preview must not access live records or the parent application.
- Publication means acknowledged store upload, never automatic installation.
