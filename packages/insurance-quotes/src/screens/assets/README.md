# Logos de aseguradoras

Copias locales de los activos de marca publicados por cada aseguradora en su
sitio oficial colombiano. Se usan únicamente para identificar la aseguradora
que emitió cada oferta dentro del comparador; no se descargan en tiempo de
ejecución.
